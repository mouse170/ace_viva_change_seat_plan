# ACE VIVA 連莊女孩｜手邊座位換位排班最佳化工具

> **線上使用網址**：[https://mouse170.github.io/ace_viva_change_seat_plan/](https://mouse170.github.io/ace_viva_change_seat_plan/)  
> **成員圖鑑與主場班表**：[https://mouse170.github.io/ace_viva_schedule/](https://mouse170.github.io/ace_viva_schedule/)

本專案為台灣職業排球聯盟（TPVL）臺中連莊職業排球隊專屬啦啦隊 **「ACE VIVA（連莊女孩）」** 之非官方粉絲自製換位排班工具。

---

## 一、 開發動機與核心功能

在臺中連莊主場賽事中，2F ACE 集氣區（A、B、C 區，每區 23 個座位）為熱門應援看台。由於女孩每局結束以及單局主隊破 10 分時均會進行站位輪調，若一群球迷朋友手邊持有多張不同區域與號碼的門票，且各自有特別想專注應援的女孩（第一志願），往往難以在局間短時間內手動算出每個人該坐哪裡。

本工具提供全自動化排班換位演算法：
1. **輸入手邊持有座位**：支援點選看台視覺化座位圖，亦可直接貼上文字（例如 `A5, B12, C19`）快速批次解析匯入。
2. **輸入參與者與心儀女孩**：每位朋友指定 1 位想看的女孩，並支援調整選位優先順序。
3. **以「局」為單位之全域最優排班**：
   * 整合官方最新公布之站位輪替數據（第 1/4 局、第 2/5 局、第 3 局）。
   * 考量「0–10 分」與「破 10 分後長時段（佔單局 60% 以上時間）」之加權距離，算出整體最優解。
   * 標註是否需要起身換位（例如「第 2 局由 B 區 6 號換至 C 區 19 號」）與本座正前方直視女孩。
4. **專屬排班圖卡生成與分享**：
   * 基於 HTML5 Canvas 技術，一鍵生成高畫質 PNG 圖卡，方便存圖傳到 LINE 群組。
   * 提供一鍵複製 LINE 格式文字排班表。
5. **本地自動記憶**：使用 `localStorage` 自動保存輸入之座位與名單，重整頁面不遺失。

---

## 二、 技術架構

* **核心框架**：React 19 + TypeScript + Vite 6
* **樣式系統**：Tailwind CSS v4（運動潮流高質感配色：深海藍 `#212047`、薄荷綠 `#5ECBC0`、金屬白金 `#5BAE84`）
* **圖卡渲染引擎**：原生 HTML5 Canvas 2D（支援 Retina 高解析度輸出與頭像非同步預載）
* **靜態發布**：GitHub Pages 自動部署

## 三、 本地開發與建置

```bash
# 1. 安裝相依套件
npm install

# 2. 啟動本地開發伺服器
npm run dev

# 3. 執行 TypeScript 型別檢查與生產打包
npm run build

# 4. 預覽打包產出
npm run preview
```
